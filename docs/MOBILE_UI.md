# 0.2.2 手机 UI 验证记录

日期：2026-10-26（Asia/Singapore）。设备与内核见 `BASELINE.md`。

用户实测 0.1 与 Chrome 流畅度基本一致，因此继续采用系统 WebView。当前安装包为 `artifacts/pure-douyin-0.2.2-mobile-debug.apk`，版本号 4，约 1.35 MB，包名 `io.github.puredouyin`。

## 实现

- 保持桌面 UA，手机模式关闭 WebView 宽视口和概览缩放，移除页面外层最小宽度；支持时在 document start 注入视口规则。
- 推荐页隐藏桌面侧栏和页头，让视频占据可用区域；保留原播放器、业务请求和视频比例。
- 原生底部入口：推荐、关注、搜索、我的。
- 上下滑使用官网的上一条/下一条入口，避开按钮、文案、进度区及已打开的评论面板。
- 评论面板重排改写自用户提供的 WhiteSevs「抖音优化」`changeCommentToBottom()`。它属于脚本适配，**不是官网原生响应式抽屉**。没有创建第二套评论列表或提交逻辑。
- 键盘出现时限制评论面板高度和底部位置，避免官网视频最小高度将输入区推到屏幕之外。
- 工具菜单中的「手机界面」可恢复原网页；关闭/开启会重建 WebView，保留站点数据。
- GPL-3.0-only 正文和来源说明随源码及 APK 提供，App「关于此原型 → 开源许可」可查看。

## 真机验证

| 检查 | 结果 |
| --- | --- |
| 构建与签名 | `assembleDebug`、`lintDebug`、APK v2 签名验证通过；Lint 0 errors / 13 warnings |

| 推荐视频区域 | 左上角为 (0,0)，宽 360，播放器高约 654，视口高 653（官网轮播保留 1px 高度差） |

| 评论区滚动 | 在评论内上滑，推荐视频索引保持 0，没有触发下一条 |
| 输入框与键盘 | 仅聚焦输入框，未输入或发布评论；视口高从 653 降为 375，面板调整至 y=48、高 327，保持在可见区内 |
