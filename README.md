# Pure Douyin 纯净抖音

> 此项目仍然处于开发中，会出现很多问题

# 简介

抖音安卓 APP 极其臃肿，有大量不实用的功能。而在电脑上使用网页浏览抖音时，我发现抖音网页版非常简洁，仅保留了抖音的核心功能。于是我突发奇想，将抖音网页版适配手机 UI，再包装成 Android APP，这样不就能实现纯净的抖音了吗？于是我决定完成此项目

此项目生成的最终安装包非常小，利用了 Android 本身的 WebView
